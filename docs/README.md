# Documentation

Public research documentation is organized by language.

- [English](en/README.md)
- [日本語](ja/README.md)
- [简体中文](zh-CN/README.md)

The three public-language directories use the same filenames. If a document is part of the public research surface, it belongs in all three directories.

## Other documentation

- [`internal/`](internal/README.md) — development and maintainer notes that are not part of the multilingual public research documentation
- [`archive/`](archive/README.md) — historical design reviews, handoffs, investigations, and other records preserved as historical provenance
- [`assets/`](assets/) — small media used by documentation

Files under `internal/` or `archive/` are intentionally not evidence of missing translations. Their location indicates that they are not part of the multilingual public documentation set.
