# docs/archive

過去時点の設計レビュー、調査記録、Part間引継ぎなどを保存する。

- ディレクトリは `YYYY-MM-DD/` 単位で分ける。
- 内容は原則として当時の記録を保持する。
- 現在の仕様へ昇格した内容は、`docs/en/`・`docs/ja/`・`docs/zh-CN/`または`docs/internal/`の現行文書へ反映する。
- 過去の実行環境を示す絶対ローカルパスが含まれている場合も、現行の導入手順ではなく当時の来歴情報として扱い、原本を不用意に書き換えない。
- archive 内の記述と現行コード・現行仕様が矛盾する場合は、現行コード・現行仕様を優先する。
