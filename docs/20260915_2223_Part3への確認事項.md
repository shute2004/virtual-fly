# Part3への確認事項

対象ブランチ: `feat/flybody-flyppy-loop`  
Part4開始時点の基準HEAD: `2f7f24db8b56e0ea0b31094881c4b488facec27a`

`docs/20260915_Flyppyライブビューア実装引き継ぎ.md` と、Part3で追加された実装・計測レポート・コミット履歴を確認したうえで、Part4の実験解釈に影響する点だけ確認したいです。

## 1. 現在のFlyppy v3 checkpointを継続学習の正規起点として扱う意図だったか

Part3中には、Flyppy v3の学習を継続しながら、神経runtime、population runtime、身体process構成、そして最終的には視覚入力がrasterからdirect-ray K=13へ切り替わっています。

特に感覚入力については、direct-ray cutover前後で入力意味論が同一ではありません。`reports/flyppy/direct_vision_cutover_benchmark.md` でも、rasterとdirect-rayではsensory semanticsが異なるためcheckpoint equalityを要求していません。

そこで確認したいです。

- 現在の `artifacts/experiments/flyppy-v3/checkpoint` は、Part3として「そのままPart4で継続学習してよい正規の学習個体」と考えていましたか。
- それとも、finalizedされた現在のproduction構成（v3 source-equivalent physics + shared-weight population + eager-live plasticity + direct-ray K=13）で、初期MaleCNSからfresh trainingをやり直した方が実験として正しいと考えていましたか。
- 現在checkpointにraster時代など異なるsensory/runtime条件で得た可塑変化が混在している場合、その混在をPart3では意図的に許容していましたか。

この点はPart4で「既存checkpointの続きを回す」か「現在の最終構成でbaselineを作り直す」かを決めるために重要です。

## 2. v3 physical seamについて、Part3終了時点で未解決と考えていた物理側の疑いは残っていたか

Part3ではv2の飛行成立性を疑い、upstream FlyBody XML、wing frame、root pitch、fluid force、measured wingbeat、source control cadenceなどを比較し、最終的にsource-equivalent v3を構築しています。

一方、最新のproduction runでは、first gateを通過するepisodeはあるものの、spawn高度を上回るepisodeがなく、長いepisodeでは高度を失っています。またsymmetric open-loop flight diagnosticはnonblocking扱いです。

確認したいです。

- Part3終了時点では、現在のv3 physical seamを「学習実験を解釈するには十分に物理側の主要問題を閉じた」と考えていましたか。
- それとも、vertical support / attitude stability / virtual-muscle torque seamなどに、まだ行動不良を説明し得る具体的な物理側の未解決疑義が残っていましたか。
- 残っていた場合、Part4が最初に見るべき診断・ファイル・実測結果はどれですか。

既に棄却された物理仮説をPart4で再調査することと、逆に未解決の物理問題を神経学習不足と誤認することの両方を避けたいです。

## 3. direct-ray K=13をどの段階まで「確定したproduction sensory seam」と見なしていたか

Part3では、RGB framebuffer経由を外し、FlyGym receptive-field footprintから構築したimage-free direct ommatidia ray sensorへproductionを切り替えています。K=13はuncompressed direct integralに対して高い相関を持ち、real learning loopでもrasterより大幅に高速でした。

一方で、rasterとのtemporal current/sign compatibilityは完全一致ではなく、photometryもOpenGL rasterの再現ではありません。

確認したいです。

- Part3としては、この差を「rasterはground truthではないため、現在のdirect-ray K=13でproduction sensory seamは確定」と判断していましたか。
- それとも、学習結果を本格的に解釈する前に、photometryやtemporal semanticsについて追加で詰める予定でしたか。
- 後者の場合、どの指標またはacceptance criterionを満たすまでsensory seamを未確定と考えていましたか。

Part4では、単にrasterへ近づけること自体を目的化せず、Part3がどこまでを解決済みと見なしていたかを正確に引き継ぎたいです。
