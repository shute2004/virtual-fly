# 神経系・可塑性モデル方針

## 1. このプロジェクトで再現したいもの

本プロジェクトは、コネクトームを人工ニューラルネットワークの配線として利用することを目的としない。

目的は、成体オスのショウジョウバエCNSを初期構造として、PC上で神経活動と可塑性を継続的に発生させることである。

したがって、コネクトームは最終形ではなく初期条件である。

```text
C(0) = observed adult male CNS connectome
C(t > 0) = C(0) + plastic changes + structural changes
```

## 2. 実測値とモデル仮定を分離する

このプロジェクトでは、次の混同を避ける。

- 実測された接続と、実装上仮定した接続強度
- 実測された神経伝達物質情報と、未観測部分への推定
- 実際の電気生理データと、数値安定性のために置いたパラメータ
- 実際の感覚器と、CNSへ入力するための補完モデル

各パラメータには可能な限り来歴ラベルを付ける。

## 3. 神経モデルの選択方針

最初から「最も詳細なモデルが正しい」とは仮定しない。

候補には、単純な発火モデル、conductance-basedモデル、区画モデル等があり得るが、採用基準は次の通りとする。

1. 対象ニューロン数・シナプス数で実行可能である。
2. 外部刺激を電気的・神経活動的入力として表現できる。
3. 神経修飾と局所可塑性を接続できる。
4. より詳細なモデルへ差し替えられる。
5. 採用した近似による欠落を追跡できる。

全CNSに同一モデルを適用することも、細胞型ごとにモデルを変えることも、実験仮説として比較できる設計にする。

## 4. シナプス

シナプスは少なくとも次の三層で扱う。

### 4.1 観測された構造

- pre / post neuron
- シナプス数
- 位置情報（利用可能な場合）
- 接続注釈

これは元データのスナップショットであり、変更しない。

### 4.2 機能状態

仮想個体側に、変更可能な状態を持たせる。

例:

- effective strength
- transmission state
- short-term state
- plasticity eligibility state
- neuromodulator sensitivity

### 4.3 構造状態

将来、形成・消失を扱う。

元データの接続を削除するのではなく、個体側の構造deltaとして表現する。

## 5. 可塑性

本プロジェクトでは「学習」を、外部optimizerによるパラメータ更新ではなく、神経活動に依存する局所変化として扱う。

概念的には:

```text
pre activity
post activity
local synapse state
neuromodulator state
recent history
        ↓
plasticity dynamics
        ↓
local synapse change
```

とする。

初期可塑性則は実装上交換可能にし、文献に基づく候補を比較する。

重要なのは、Flappy環境のスコアを直接読んでシナプスを書き換えないことである。

## 6. 神経修飾

成功・失敗は、数値報酬として神経系へ与えない。

実験層はイベントを、対応する神経刺激へ変換する。

例:

```text
successful passage
   ↓
reward-related dopaminergic stimulation

collision / failure
   ↓
aversive-related stimulation
```

どの細胞群、刺激強度、刺激時間が適切かは、文献・実測情報を調査して実験条件として明示する。

PAM/PPL1等を単純に「+/- reward neuron」と固定的に解釈せず、細胞型・投射先・課題依存性を調査してから採用する。

## 7. 構造可塑性

最終目標では、シナプスの強弱だけでなく形成・消失も扱う。

ただし構造形成規則を勝手に作ると、元の目的から離れるため、段階的に導入する。

### Stage A

既存接続のみ。強度・機能状態が変化する。

### Stage B

既存接続の機能的無効化・再活性化を許す。

### Stage C

新規接続形成・恒久的除去を許す。

Stage Cは、生物学的根拠と計算上の候補生成規則を明示してから実装する。

## 8. 感覚入力

学習データを直接CNSへテンソルとして与えない。

視覚なら:

```text
3D scene
  ↓
compound-eye sampling
  ↓
peripheral visual transduction
  ↓
activity at CNS visual entry neurons
```

とする。

MaleCNSに含まれない網膜・末梢感覚器については、別モジュールで補完する。

## 9. 運動出力

行動ラベルを神経系に付けて選択させない。

```text
neural activity
  ↓
descending / motor pathways
  ↓
muscle or actuator mapping
  ↓
body dynamics
```

とする。

初期版で身体アクチュエータを直接駆動する場合も、その写像は神経解剖学的対応を表すだけで、環境を見て行動を決めるロジックを持たせない。

## 10. 自発活動

仮想ハエが外部命令なしに動き始めることを可能にする。

そのため、神経系を「入力があるときだけ評価する関数」にしない。

候補として以下を検討する。

- baseline activity
- spontaneous firing
- intrinsic dynamics
- tonic neuromodulatory drive
- sensory background

どれを採用するかは、ショウジョウバエの実測知見を確認して決める。

「前進させるための隠れたゲームロジック」を入れるのではなく、生体の自発運動に相当する状態を神経系側で作る。

## 11. 検証

各レイヤは、ゲーム成績だけで評価しない。

### 神経レベル

- 活動率
- 発火・状態分布
- 伝播遅延
- 特定回路の応答
- 神経修飾による変化

### シナプスレベル

- 強度分布
- 強化・弱化率
- 可塑性の局在
- 形成・消失率

### 行動レベル

- 自発運動
- 刺激応答
- 学習前後の変化
- 保持
- 消去
- 一般化

を分けて見る。

## 12. 最重要原則

「ハエらしく見える結果」を出すために、内部へ見えないAIを追加しない。

結果が悪くても、仮想脳が実装した神経機構から生じた結果をそのまま観測する。

このプロジェクトの価値は、Flappy Birdのスコアではなく、実測された神経構造と生物学的可塑性の近似だけから、どのような学習・行動が自発的に現れるかを調べることにある。
