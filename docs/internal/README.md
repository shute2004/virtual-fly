# Internal documentation

This directory contains maintainer and development notes that are intentionally outside the multilingual public research-documentation set.

Language is part of the path so a file cannot be mistaken for a missing translation.

- [`en/`](en/README.md) — internal English maintainer notes
- [`ja/`](ja/README.md) — internal Japanese development notes

Documents here may describe implementation history, development procedures, or planning. Public scientific claims should instead follow `docs/en/`, `docs/ja/`, or `docs/zh-CN/` and the canonical experiment package.
