# 開発ロードマップ

## 方針

全CNS、大規模な3D身体、Web上の分散実験を一度に作らない。

各段階で「何が動けば次へ進めるか」を明確にし、科学モデルとソフトウェア基盤を同時に検証する。

## 段階0: データと外部資産の固定

### 作業

- MaleCNS `male-cns:v1.0`の取得方法を実装する。
- neuPrint APIと一括配布データのどちらを基準入力にするか決める。
- ニューロン、シナプス、注釈の内部形式を定義する。
- FlyBody / FlyGym / MuJoCoの使用版を固定する。
- 外部資産のライセンス、引用情報、ハッシュ値を記録する。
- MaleCNSに含まれる感覚・末梢構造と、含まれないものを一覧化する。

### 終了条件

- 同じ入力版から同じ内部コネクトームスナップショットを再生成できる。
- データの来歴を機械可読な記録として残せる。

## 段階1: 最小の神経実行系

### 作業

- Rustワークスペースを作る。
- ニューロン状態配列を実装する。
- 疎な接続格納形式を実装する。
- 小規模な部分グラフで時間発展を実装する。
- 外部刺激の注入を実装する。
- Pythonとの連携層を作る。
- 決定論的な試験を用意する。

### 終了条件

- 小規模神経回路へ刺激を与え、活動伝播を追跡できる。
- 同じ乱数種と状態から同じ結果を再現できる。

## 段階2: 機能可塑性と神経修飾

### 作業

- 可塑性の実装境界を定義する。
- 最初の文献に基づく可塑性則を実装する。
- 神経修飾状態を実装する。
- 報酬・嫌悪回路への刺激イベントを実装する。
- シナプス強度変化を保存・可視化する。
- 可塑性を停止した対照条件を、同じ実行系で動かせるようにする。

### 終了条件

- 同じ入力への応答が、経験後に持続的に変化する実験を構成できる。
- 変化したシナプスを追跡できる。

## 段階3: 全CNS規模

### 作業

- MaleCNS全体を読み込む。
- メモリ使用量と1時間刻みあたりの性能を測定する。
- 疎接続表現とイベント処理を最適化する。
- 活動の暴走・消失を検出する診断を作る。
- CPU参照実装と高速実行方式の一致を検証する。

### 終了条件

- 全CNS相当の状態を一定時間、安定してシミュレートできる。
- チェックポイントの保存・再開ができる。

## 段階4: 身体と感覚

### 作業

- FlyBody / FlyGymとの接続層を実装する。
- 3次元環境から複眼入力を生成する。
- 視覚末梢系からMaleCNS入口への変換を実装する。
- CNS運動出力から身体駆動部への最初の対応付けを作る。
- 身体から固有感覚・接触情報を返すための境界を作る。

### 終了条件

- `環境 → 感覚 → CNS → 運動 → 身体 → 環境`の閉ループが成立する。
- ゲーム攻略用の外部規則なしで、身体が神経活動に応じて動く。

## 段階5: 自発活動と既知応答の検証

### 作業

- 基礎活動・自発活動の条件を調査し、実装する。
- 単純な視覚刺激への応答を検証する。
- 既知のショウジョウバエ神経・行動データと比較する。
- 神経モデルで不足している部分を特定する。

### 終了条件

- 外部の行動命令なしで、神経系と身体が継続動作する。
- 少なくとも一部の既知刺激応答を、定性的または定量的に比較できる。

## 段階6: Flyppy v0

### 作業

- 最小の障害物環境を作る。
- 成功・失敗イベントを定義する。
- イベントを報酬・嫌悪回路への刺激へ変換する。
- 可塑性あり、可塑性なし、非随伴刺激、対応刺激対照を自動実験する。
- 行動、神経、シナプスの指標を記録する。

### 終了条件

- 多数の同一初期個体を分岐して比較できる。
- 行動変化を神経系変化と対応付けて解析できる。

## 段階7: 構造可塑性

### 作業

- 接続形成・消失規則の文献調査を行う。
- 構造差分を保持する層を実装する。
- 新規接続候補の探索を局所化し、計算量を制御する。
- 構造変更をチェックポイントへ保存する。
- 機能可塑性だけを使う場合との比較を行う。

### 終了条件

- 接続形成・消失を含む個体状態を保存・再現できる。
- 構造変更が行動・神経活動へ与える影響を追跡できる。

## 段階8: 高速化と大量個体

### 作業

- 複数個体の並列実行を実装する。
- GPU実行方式を評価する。
- 実験結果を効率よく保存・集計する形式を整備する。
- 数百〜数千個体規模の実験管理を行う。

### 終了条件

- 大量個体の比較実験を自動実行できる。
- 同一初期脳から経験によって分岐した結果を統計解析できる。

## 段階9: Web公開

### 作業

- 3D表示と神経活動可視化を作る。
- WASM版の神経実行系を作る。
- WebGPUを使う範囲を決める。
- 計算参加への明示的な同意画面を作る。
- 実験の配布と結果送信を実装する。
- 端末から返る結果の検証と重複排除を実装する。

### 終了条件

- 一般利用者がブラウザで仮想ハエを観察できる。
- 同意した利用者の計算機で実験個体を実行できる。
- 収集結果から再現可能な実験データセットを構築できる。

## 段階10: 公開実験基盤

最終段階では、公開サイトを単なる実演ではなく、分散実験の基盤として運用する。

候補機能:

- 現在活動中の仮想個体数
- 累計仮想経験時間
- 個体ごとの系譜
- 学習前後の行動比較
- 神経・シナプス変化の可視化
- 実験条件別の集計
- 再現実験の自動割り当て

## 優先順位

最優先は段階0〜2である。

「3Dのハエを見せる」より先に、**神経系が動き、経験によって内部状態が変わり、その状態を検証可能な形で保存できること**を成立させる。
