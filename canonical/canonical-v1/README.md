# Canonical experiment v1

This directory is a **fresh current-semantics reference experiment** generated from clean commit `7fa464aad7269d34f46f1171080b51e095d1d811` (`dirty=false`).

It is not a regeneration of v240, v960, v966, v1704, or the posting Before/After experiment. Those remain historical lineages with different provenance.

## Scope

Fresh official MaleCNS v1.0 raw files and fresh FlyBody wingbeat source were downloaded in the isolated checkout. All snapshot-derived maps, class-DAN roles, the 97-neuron haltere timing subset, neutral trim, neural calibration, viewer graph and PlasticFastGraph analysis were generated by this commit.

Training used body v7 / environment v7 / direct-ray K13 / haltere timing subset (`gain=0.05`, `interaction-load-v2`), population 2, async shared weights, boundary-band curriculum, and 6 episodes.

Frozen comparison uses plasticity **OFF** and DAN stimulation **OFF** (`reward_current=0`, `aversive_current=0`) so the comparison isolates stored weight state as far as the current model permits. Both initial and final evaluations passed Gate 1 and collided with the next gate at control step 120.

Recorded reference provenance and result are stored in `reference-manifest.json` and `reference-report.md`.

`reproduce.sh` writes each end-to-end verification run outside the repository by default, under `${XDG_CACHE_HOME:-$HOME/.cache}/virtual-fly/reproductions/`. Set `VF_CANONICAL_OUTPUT_ROOT` to choose a different output directory. This changes only storage placement; the pinned scientific commit and canonical experiment conditions are unchanged.
